Racing 8 DX Recomp for Windows (TEST BUILD)

1. Keep this folder anywhere you like (a USB drive works). Everything the program writes goes into the "userdata" folder inside it.
2. Run kartrecomp.exe. On the Setup tab pick your own files: base game (.nsp), the 3.0.4 update (.nsp), prod.keys, firmware (folder or .zip),
   and optionally DLC. The launcher will MOVE the .nsp files into userdata (it asks first).
3. Press Build game (about 5-15 minutes, needs ~3 GB free RAM and ~7 GB free disk), then Play.
4. If anything goes wrong, run Collect-Logs.cmd: it writes kartrecomp-logs.zip in this folder (logs and settings only, no game files or keys).
   Send that file back.

No game files, keys or firmware are included. Windows SmartScreen may warn about an unsigned program: choose "More info", then "Run anyway".
